# KGZ HC — Dark Edition

React + Vite redizajn KGZ stranice. **Dark mode je zadana tema**, a prekidač Sun/Moon mijenja light/dark i pamti izbor u `localStorage`. Ostale demo interakcije ostaju funkcionalne.

## Pokretanje

Zahtijeva Node.js 20.19+ ili 22.12+ i npm.

```bash
npm install
npm run dev
```

Otvori adresu koju ispiše Vite (najčešće http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

Ovo je neslužbeni demo koncept; nema povezan KGZ katalog ni CMS. Slike u `public/images` su lokalne; hero fotografija koristi Unsplash.
